## 一、作品信息

- **工作台名称**：KPOP NOTE · 日报 × 记录
- **模板文件**：`kpop-note-workspace.html`（单文件全内联，124 KB，无外部依赖）
- **模板链接**：上传 WorkBuddy 资料库后 → 打开该文件 → 右上角「分享」→「发布为网站」→ 复制 `https://workbuddy.link/p/xxxx` 链接填入

## 二、一句话介绍

> 一本装下 KPOP 粉丝全部日常的追星工作台——资讯日报、回归日程、周边收藏、Con 记忆、追星账本，数据在线存储、多端双向同步。

## 三、适用场景（填写用）

KPOP 粉丝的追星日常管理：记录本命团体回归期 / 先行曲 / 专辑发行 / Showcase / 巡演 / 生日周年 / 抢票状态；收藏专辑、小卡、周边并跟踪种草→在途→到手→出物全流程；沉淀每场线下演唱会的座位、心情、歌单与花销明细；自动汇总追星总账、品类占比、月度趋势与年度预算提醒。

## 四、解决什么问题（填写用）

追星信息散落在微博超话、票务平台、购物记录里，日程容易错过、花钱没有概念。本工作台把「资讯」与「个人记录」合二为一：日报看到回归新闻可一键加入日程；收藏与 Con 花销自动进账本，品类占比与预算进度条直观可见，防止冲动剁手。数据存于资料库云端，页面 ↔ CSV 表格双向同步，换设备登录不丢数据，也能导出/导入 CSV 随时备份。

## 五、适用人群（填写用）

KPOP 粉丝、追星女孩 / 男孩、多担（multi-stan）、演唱会常客、周边收藏爱好者；尤其适合同时追多个团体、需要管住追星预算的粉丝。

## 六、发布与同步操作指引

1. 打开 WorkBuddy → 左侧「更多」→「资料库」（或在任务中直接把文件存入资料库）；
2. 上传 `kpop-note-workspace.html`（也可用「导入」从本地选择）；
3. 打开该文件：资料库将 HTML 页面与配套 CSV 数据表关联——**在表格里改一条，页面跟着变；在页面里新增/编辑，表格自动写回**，数据存在云端；
4. 右上角「分享」→「发布为网站」→ 复制模板链接；
5. 打开发布链接截图 1-3 张（建议：日报首页 / 收藏区 / 账本统计区），随表单提交。

> 兼容说明：若当前资料库环境未自动注入同步运行时，页面会自动降级为浏览器本地存储（键 `wb_kpop_note_v1`），全部功能不受影响；并可在「账本」页使用「导出 CSV / 导入 CSV」手动同步与备份。
